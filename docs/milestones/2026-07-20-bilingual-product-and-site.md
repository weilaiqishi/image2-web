# 里程碑：双语产品与公开站点

完成区间：2026-07-18 至 2026-07-20  
代表提交：`b915deb`、`baaec3d`、`096938b`、`aaf6bdf`、`9ec36f8`、`b2b43b0`、`9bf2631`、`202f3b0`

## 交付结果

这一阶段把桌面功能扩展为可公开展示、下载和部署的双语产品，并补齐站点安全、发布校验与广告合规基础。

### 桌面产品

- 桌面工作区支持中文和英文界面。
- Studio 主界面与标注编辑器重新设计，生成案例用于说明真实使用场景。
- 网关设置收敛到统一入口，降低 Base URL、Agent 协议与图片模型配置分散造成的理解成本。
- 图文操作手册覆盖连接设置、参考图角色、队列、灵感库、精准编辑和版本继续。

### 营销与分发

- 建立中英文 Cloudflare 静态站点和语言路由。
- 增加案例、指南、关于、隐私及真实 404 页面。
- 构建脚本生成 canonical、站点地图、robots、社交图片和安全响应头。
- 展示八类生成案例，并同步桌面界面截图与产品定位。
- 发布工作流校验 macOS、Windows 安装包与 `SHA256SUMS`，避免发布资产校验值失真。

### 隐私与广告准备

- 广告位默认不加载第三方脚本，未配置时保持静态占位。
- 隐私页区分桌面本地数据边界、Cloudflare 托管数据与广告处理范围。
- AdSense 发布商验证与广告投放配置分离；只有广告位、合规确认等条件完整时才允许投放。
- Secret Scan 和站点验证覆盖 API Key 泄露、软 404、CSP、广告域名和公开资源完整性。
