DESKTOP SYSTEM

不是又一个输入框。

Image2 把对话、参考图、生成参数、串行任务和版本结果放进同一个安静的桌面工作面。Key 留在系统凭证库，图片和会话留在本机。

01 / CONNECT

接入你的网关

自定义 HTTPS Base URL、Responses 或 Chat Completions、Agent 模型与图片模型。

02 / COMPOSE

描述目标与参考

参考图可以分配身份、产品、姿势、构图、材质和风格角色，不再混成一团。

03 / CONTROL

严格串行执行

每个方向都是独立任务。停止、恢复、失败重试和额度控制都有明确状态。

04 / REFINE

从任意版本继续

用区域标注说明局部修改，保留父子版本关系，并随时从旧结果另开分支。

TASK PIPELINE

复杂需求，按顺序落地。

Agent 负责理解和拆分，桌面端负责把每次付费调用变成可见、可停、可恢复的任务。

  1. INPUT

    写目标，放参考

    一句需求可以同时包含主体、风格、文字、比例与多个参考图。

    01
  2. PLAN

    Agent 拆成独立图片

    每张图都有明确标题、提示词、参数和参考关系，发送前就能确认。

    02
  3. RUN

    队列严格串行

    任何时刻只执行一项图片任务，避免网关限流与意外并发费用。

    03
  4. ITERATE

    标注并继续修改

    点、框、箭头和画笔区域进入结构化编辑请求，未标注区域要求保持。

    04
