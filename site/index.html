常见问题

先把关键问题说清楚。

Image2 Studio 和普通 AI 生图网站有什么不同？

它不是按月售卖另一套模型额度，而是把你已有的 OpenAI 兼容中转变成更适合家人使用的本地工作台。重点是自然语言任务拆解、参考图分工、精准标注和可恢复的串行队列。

支持哪些中转和模型？

中转需要提供 HTTPS Base URL，并兼容 Responses API 或 Chat Completions，以及 OpenAI Images 的 generations 和 edits 端点。Agent 与图片模型名称都可以自定义。

家人需要接触 API Key 吗？

第一次仍需要由你在他们使用的电脑上完成连接设置。保存后，桌面端只显示“已保存在系统凭证库”，日常生成不需要再次查看或粘贴密钥。

Cloudflare 上的在线演示会产生费用吗？

不会。公开演示只使用本地模拟 Agent 和示例素材，不调用真实图片接口。真实请求只从桌面端发往你配置的中转。

Cloudflare Pages 免费档够用吗？

对个人项目的静态宣传站和模拟演示通常足够，而且不需要数据库或 Worker。实际额度与条款可能变化，部署前请以 Cloudflare 当前官方说明为准。
