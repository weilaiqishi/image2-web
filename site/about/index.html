关于 Image2

Image2 Studio 是面向 OpenAI 兼容中转网关的本地图片任务工作台。它让 Base URL、API Key 与 gpt-image-2 不只停留在一次提示词调用，而成为可计划、可排队、可编辑、可回溯的桌面工作流。

为什么做 Image2

兼容 OpenAI 协议的网关让模型接入更灵活，但通用聊天客户端通常不会替你管理图片参考关系、局部编辑、付费调用顺序和父子版本。Image2 把这些图片工作所需的结构放在一个安静的桌面界面里。

从网关到图片任务

你配置 HTTPS Base URL、API Key、Agent 协议与模型名称。Agent 理解目标并拆成独立图片任务；桌面端按严格串行队列执行调用，让停止、恢复、失败重试和额度控制保持可见。参考图可以承担身份、产品、姿势、构图、材质或风格角色，区域标注则进入结构化编辑请求。

准确的数据边界

API Key 保存在 macOS Keychain 或 Windows Credential Manager。会话、任务、图片与标注保存在本机。生成和编辑请求会发送到你配置的网关，并受该网关及其上游服务条款约束。营销网站与桌面工作区分离，不接收 Key，也无法读取本地项目内容。

公开开发

Image2 的源码、版本和开发记录公开在 GitHub。你可以检查实现、下载 Releases、报告可复现的问题，或通过 Pull Request 参与改进。提交问题时请提供必要的环境与复现步骤，但不要公开 API Key、访问令牌或含敏感信息的日志。

联系项目

功能建议、缺陷报告和文档问题统一通过 GitHub Issues 跟踪，便于让讨论、状态和修复结果保持公开可追溯。
