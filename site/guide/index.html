OPERATIONS GUIDE / 01-08

Image2 操作指南

从一组已有的中转站 Base URL 与 API Key 开始，把自然语言目标、参考图、付费调用和版本结果组织成可检查的桌面工作流。

安装连接网关第一次生成参考图区域编辑串行队列版本管理故障排查

STEP / 01

安装桌面端

只从 GitHub Releases 下载与系统匹配的安装包。当前构建未签名，macOS 或 Windows 可能显示安全提示；先核对发布页中的文件名和 SHA256SUMS，再按系统提示继续。

不会进入网页的内容API Key、对话、参考图和生成结果都不应粘贴到宣传站。它们只在桌面应用和你配置的网关之间使用。

STEP / 02

连接 OpenAI 兼容网关

首次启动会打开网关设置。依次填写 HTTPS Base URL、API Key、Agent 协议、Agent 模型和图片模型。图片模型默认使用 gpt-image-2；Agent 与图片接口共用同一组 Base URL 和 Key。

BASE URL
远程地址必须使用 HTTPS；仅本机 localhost 可使用 HTTP。
API KEY
由 Rust 后端写入 macOS Keychain 或 Windows Credential Manager。
PROTOCOL
按中转站能力选择 Responses API 或 Chat Completions。
MODEL
模型名称必须与中转站实际开放的名称一致。

STEP / 03

完成第一次生成

在对话中写清主体、用途、画幅、风格与必须保持的约束。Agent 会先拆成图片任务；发送前检查标题、提示词、尺寸和参考关系，再进入串行队列。

为一款无品牌的黑色桌面音响生成 1:1 产品摄影。
石材底座，克制的青色边缘光，不出现文字、Logo 或水印。

STEP / 04

给参考图分配明确角色

不要只说“参考这些图”。分别说明哪张图负责身份、产品结构、姿势、构图、材质、色卡或视觉风格，并写明冲突时的优先级。这样 Agent 才能把引用关系编译进每个任务。

  • 身份：保持人物脸型、五官、年龄感和发型。
  • 结构：保持产品比例、零件位置和可制造关系。
  • 构图：只迁移主体位置、镜头方向和留白。
  • 风格：只迁移光线、色彩和媒介气质，不替换主体。

STEP / 05

用标注限定局部修改

从一个已有版本继续，使用点、框、箭头或画笔标出需要变化的区域。标注只是给模型的定位信息，最终图必须移除标注，并保持未标注区域。

STEP / 06

让付费调用严格串行

Image2 同一时间只执行一项图片任务。停止会阻止新任务开始；恢复从等待项继续；失败项保留错误和参数，确认网关额度、模型名与接口能力后再重试。

成本边界Agent 规划和图片生成都可能产生网关费用。先检查拆分数量，再启动队列。

STEP / 07

从任意版本继续

每个结果都保留父子关系。你可以重命名版本、隐藏不再使用的结果、从旧版本另开分支，或把当前版本重新放回编辑上下文。隐藏不会破坏文件与版本关系。

STEP / 08

按错误所在阶段排查

401 / 403
重新确认 Key、网关权限和模型授权，不要把 Key 发到网页或 Issue。
404
检查 Base URL 是否包含正确的 /v1 路径，以及协议端点是否存在。
429
等待额度恢复；保持串行，不要通过多开窗口绕过限流。
INVALID JSON
Agent 返回格式不符合任务协议；切换受支持模型或协议后重试。

公开反馈请使用 GitHub Issues，只提交可复现步骤和已脱敏错误，不要附带 Key、完整网关响应或私人图片。
