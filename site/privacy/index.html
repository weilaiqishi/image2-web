LEGAL / PRIVACY

隐私与 Cookie

Image2 桌面应用与这个营销网站是两个独立的数据边界。下面说明各自处理什么，以及展示广告启用后你可以如何选择。

最后更新：2026 年 8 月 5 日

桌面应用与营销站分开

Image2 Studio 桌面应用不会把 API Key 提交给本营销网站。API Key 保存在操作系统凭证库中；会话、任务、图片与标注保存在本机。应用发起生成或编辑时，请求会直接发送到你配置的 OpenAI 兼容网关，因此该网关及其上游服务的隐私条款也适用于这些请求。

本营销网站不接收 API Key，不提供在线生成，也无法读取桌面应用中的会话或图片。

网站交付所需的技术数据

网站由 Cloudflare Pages 托管。为交付页面、保障安全和诊断故障，托管与网络服务可能处理 IP 地址、请求时间、请求 URL、浏览器或设备信息以及安全事件数据。更多信息请参阅 Cloudflare 隐私政策。

广告提供商与你的选择

本次构建启用的广告提供商是：__AD_PROVIDER__。构建配置最多选择一个提供商；不会在同一广告位同时加载 Google AdSense 与 Adsterra。两者的加载方式不同：Google AdSense 仅在明确同意后加载；Adsterra 启用时，固定的已批准标签出现在中英文首页、指南、案例和 Codex 排障文章共 8 个广告位，并在页面解析时立即加载，不会先显示同意提示。

选择 Google AdSense 时，本站默认只请求非个性化广告。即便如此，Google 及参与的广告技术供应商仍可能使用 Cookie 或类似技术，并处理 IP 地址、设备与浏览器信息、当前页面信息以及广告展示和互动数据，用于广告投放、衡量、安全与反作弊。详细说明请参阅 Google 使用合作伙伴网站信息的方式和 Google 隐私权政策。

选择 Adsterra 时，本站只允许为已获批准的网站和广告位加载普通 Display Banner，不接入 Popunder、Push、Direct Link 或 Social Bar。Adsterra 的政策说明其可能处理 IP 地址、浏览器类型与版本、时区和大致位置、操作系统与平台、访问 URL、页面互动及广告相关技术数据，也可能使用 Cookie 或类似技术。请参阅 Adsterra 隐私政策和 Adsterra 发布商条款。

Google AdSense 的同意界面允许拒绝加载；拒绝不会阻止你阅读网站内容或前往 GitHub 下载 Image2。Adsterra 生产构建不提供这项加载前选择。

Cookie、本地存储与同意记录

Google AdSense 的广告隐私控件使用本地存储记住你的选择。Adsterra 标签不使用本站的本地存储作为加载闸门；它及其加载的广告资源可能使用 Cookie 或类似技术。除提供网站、支持 AdSense 隐私选择和展示广告所需的数据外，本网站不要求你建立账户，也不接收图片生成内容。

广告隐私选项

使用 Google AdSense 时，页面会提供加载前的同意界面，你也可以在 Google 我的广告中心管理 Google 的个性化广告设置。Adsterra 启用时不会显示这项同意或重置控件；离开排障文章可以避免该页面之后的加载，但无法撤销广告提供商已经处理的数据。

外部链接

本网站会链接到 GitHub、Google、Cloudflare 等第三方服务。离开本站后，相应第三方的条款和隐私政策适用。请勿在公开 GitHub Issue 中提交 API Key、访问令牌或其他敏感信息。

政策更新与联系

如果网站的数据处理方式发生实质变化，本页会同步更新日期和内容。有关本政策或 Image2 项目的问题，请通过 GitHub Issues 联系维护者。
