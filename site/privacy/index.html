LEGAL / PRIVACY

隐私与 Cookie

Image2 桌面应用与这个营销网站是两个独立的数据边界。下面说明各自处理什么，以及展示广告启用后你可以如何选择。

最后更新：2026 年 7 月 19 日

桌面应用与营销站分开

Image2 Studio 桌面应用不会把 API Key 提交给本营销网站。API Key 保存在操作系统凭证库中；会话、任务、图片与标注保存在本机。应用发起生成或编辑时，请求会直接发送到你配置的 OpenAI 兼容网关，因此该网关及其上游服务的隐私条款也适用于这些请求。

本营销网站不接收 API Key，不提供在线生成，也无法读取桌面应用中的会话或图片。

网站交付所需的技术数据

网站由 Cloudflare Pages 托管。为交付页面、保障安全和诊断故障，托管与网络服务可能处理 IP 地址、请求时间、请求 URL、浏览器或设备信息以及安全事件数据。更多信息请参阅 Cloudflare 隐私政策。

Google AdSense 与你的选择

本网站可能使用 Google AdSense 展示广告。在你做出选择前，本网站不会加载 Google AdSense 广告标签，也不会发起广告请求。本站的广告隐私控件只会在浏览器本地记录你的选择。

如果你同意，本站只请求非个性化广告。即便如此，Google 及参与的广告技术供应商仍可能使用 Cookie 或类似技术，并处理 IP 地址、设备与浏览器信息、当前页面信息以及广告展示和互动数据，用于广告投放、衡量、安全与反作弊。详细说明请参阅 Google 使用合作伙伴网站信息的方式和 Google 隐私权政策。

如果你拒绝，本网站不会请求展示广告。拒绝广告不会阻止你阅读网站内容或前往 GitHub 下载 Image2。

Cookie、本地存储与同意记录

本站的广告隐私控件使用本地存储记住你的选择。Google AdSense 在启用后可能使用 Cookie 或类似技术；除提供网站、记住隐私选择和在你同意后展示广告所需的数据外，本网站不要求你建立账户，也不接收图片生成内容。

管理或撤回同意

你可以随时重新打开本站的广告隐私选项。如果广告已经加载，撤回时页面会刷新以停止之后的广告请求；撤回无法撤销 Google 此前已经处理的数据。你也可以在 Google 我的广告中心管理 Google 的个性化广告设置。

外部链接

本网站会链接到 GitHub、Google、Cloudflare 等第三方服务。离开本站后，相应第三方的条款和隐私政策适用。请勿在公开 GitHub Issue 中提交 API Key、访问令牌或其他敏感信息。

政策更新与联系

如果网站的数据处理方式发生实质变化，本页会同步更新日期和内容。有关本政策或 Image2 项目的问题，请通过 GitHub Issues 联系维护者。
