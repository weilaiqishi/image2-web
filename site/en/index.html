DESKTOP SYSTEM

Not another prompt box.

Image2 puts conversations, references, generation controls, serial tasks, and versioned results on one quiet desktop surface. Your key stays in the OS credential store; images and conversations stay local.

01 / CONNECT

Use your gateway

Enter an HTTPS Base URL and API key, choose the agent protocol, and set the agent and gpt-image-2 model names.

02 / COMPOSE

Describe and reference

Assign identity, product, pose, composition, material, and style roles to references.

03 / CONTROL

Run a strict queue

Every direction is its own task, with clear stop, resume, retry, and cost-control states.

04 / REFINE

Continue from any version

Mark regions for local changes, preserve parent-child history, and branch from older results.

TASK PIPELINE

Complex requests, executed in order.

The agent understands and plans. The desktop app turns every paid call into a visible task you can stop, resume, and inspect.

  1. INPUT

    Write the goal, add references

    One request can combine subjects, style, copy, ratio, and multiple reference images.

    01
  2. PLAN

    Split it into images

    Every output has a title, prompt, parameters, and explicit reference relationships.

    02
  3. RUN

    Execute strictly in series

    Only one image task runs at a time, avoiding gateway rate limits and surprise concurrency costs.

    03
  4. ITERATE

    Mark and continue

    Points, boxes, arrows, and painted regions compile into a structured edit request.

    04
