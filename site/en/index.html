Frequently asked

Clear answers before setup.

How is Image2 Studio different from a regular AI image site?

It does not sell another monthly pool of model credits. It turns the OpenAI-compatible relay you already have into a local workspace built around natural-language task planning, reference roles, precise annotations, and a resumable serial queue.

Which relays and models are supported?

The relay needs an HTTPS Base URL and must support Responses API or Chat Completions plus the OpenAI Images generations and edits endpoints. Both agent and image model names are configurable.

Does the family ever need to handle the API key?

You still complete the first connection setup on the computer they will use. Once saved, the desktop app only shows that the key is in the system credential vault, so normal generation does not require seeing or pasting it again.

Can the Cloudflare demo spend relay credit?

No. The public demo uses a local mock agent and bundled example assets. It never calls the real image endpoints. Real requests only leave the desktop app for the relay you configured.

Is the Cloudflare Pages free tier enough?

It is usually enough for a personal static marketing site and mock demo, with no database or Worker required. Limits and terms can change, so check the current official Cloudflare documentation before launch.
