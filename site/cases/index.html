GENERATION LEDGER / 001-008

八个原创生成案例

这些不是素材图库样张。每个案例都记录了任务类型、构图要求、约束和验收重点，展示如何把模糊方向整理成可以进入串行队列的图片任务。

人物产品餐饮界面空间角色插画分镜

PORTRAIT / 01

蓝调拱廊人物

目标是可信的商业时尚摄影，而不是磨皮人物海报。提示词同时限定自然皮肤、潮湿反射、克制未来服装与蓝冷环境光。

雨后混凝土拱廊，原创东亚创意从业者三分之二身竖构图。
自然皮肤，炭灰技术夹克，青色实景灯与一条暖色轮廓光。
无品牌、无文字、无水印，手部与面部结构真实。
CHECK
身份原创，皮肤有纹理，人物与雨面反射处在同一光线环境。
AVOID
网红脸、塑料皮肤、品牌服装、错误手指和装饰性文字。

PRODUCT / 02

石墨音响产品图

先规定可制造的结构和材质，再添加棚拍语言。模型需要给出可信的开孔、控制件和边缘，而不是一个只有轮廓的黑盒。

虚构高端无线音箱，哑光石墨外壳，深色矿物台座。
精确机械开孔与可触摸控制件，棚拍条形灯，青色边缘高光。
无品牌名、无可读文字、无 Logo、无水印。
CHECK
结构可制造，材质区分清楚，轮廓光没有吞掉产品边缘。
AVOID
随机按钮、悬浮零件、伪品牌、无法解释的发光纹路。

EDITORIAL / 03

午夜面馆

餐饮图的重点是人物关系与食物状态同时可信。任务明确厨师上菜的动作、朋友视线和冷热光平衡，避免只有一碗食物的静物图。

紧凑现代面馆的晚间纪实场景，厨师在不锈钢台面上菜，
两位朋友自然靠近。暖色操作灯与窗外冷色街灯平衡。
食物和手部真实，不出现店名、Logo、菜单文字或水印。
CHECK
人物视线与动作连贯，碗和台面接触关系正确，食物仍有热度。
AVOID
摆拍笑容、重复手指、乱码菜单、虚构连锁品牌。

INTERFACE / 04

创意任务控制台

界面案例要求先像一款可以交付的软件，再像一张广告图。提示中明确设备层级、图片队列、参考缩略图与状态信号，限制已知品牌 UI。

一台平板和一部手机展示虚构创意任务应用：暗色图片队列、
参考缩略图、清晰控制和青色状态点。设备放在哑光黑工作台。
界面层级实用，不复制任何已知产品，不出现 Logo 或水印。
CHECK
设备透视一致，界面密度合理，状态和控件具备真实产品逻辑。
AVOID
纯概念 HUD、无意义图表、品牌图标、过度发光和不可读密文。

SPACE / 05

冷海悬崖工作室

空间生成先守住可建造性。黑化木、玻璃、海岸天气和室内暖光形成材料关系，同时明确禁止无法落地的巨大悬挑。

冷海悬崖上的黑化木与玻璃创作工作室，室内工作面透过立面可见。
阴天黎明、轻雾、少量暖光。几何结构可建造，无夸张悬挑。
无文字、无 Logo、无水印。
CHECK
柱墙受力关系可信，室内外尺度一致，玻璃反射保留空间深度。
AVOID
悬空体块、无入口建筑、重复窗格和电影式过度雾化。

CHARACTER / 06

轨道舱工程师

角色方向从职业与工具出发，而不是借用现成 IP。紧凑工具服、维修舱和手持头盔共同说明身份，避免超级英雄盔甲。

老旧轨道维修舱中的原创工程师，紧凑模块化工具服，头盔拿在髋侧。
工业现实主义、工人阶层未来，不使用武器或英雄盔甲。
角色与装备原创，无系列引用、文字、Logo 或水印。
CHECK
装备与职业相符，双手解剖正确，角色和环境磨损程度一致。
AVOID
影视 IP 轮廓、战术武器、悬浮配件和无功能装甲。

ILLUSTRATION / 07

玻璃鲸档案馆

超现实主题通过媒介约束保持成熟：墨色、剪纸和透光玻璃各自承担材质，不依赖儿童卡通造型。

透明玻璃鲸漂浮在夜间档案馆，纸张像星群散开，书架轻微弯向远处。
精致混合媒介编辑插画：墨、剪纸与发光玻璃。
克制成熟，无文字、Logo、水印或儿童卡通风格。
CHECK
纸张、墨和玻璃有清楚材质差异，鲸与空间存在光线联系。
AVOID
童书脸、霓虹泛滥、随机书脊文字和纯 3D 塑料质感。

STORYBOARD / 08

凌晨列车四镜

分镜不是四张无关图片。任务锁定同一列车、站台、时间和摄影语言，并为四格分别指定到站、门部、乘客和离站镜头。

同一列电车在黎明前抵达同一雾中山站的四格电影分镜：
全景到站、车门细节、独行乘客剪影、列车驶入雾中。
严格 2×2 等分网格，连续场景，无标题、文字、Logo 或水印。
CHECK
正好四格，列车和站台连续，镜头顺序形成完整动作。
AVOID
多于四格、地点跳变、车型漂移、字幕和不一致调色。
